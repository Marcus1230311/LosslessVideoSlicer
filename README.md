# 无损视频切片器 / Lossless Video Slicer

一个专注于 **单视频快速切片、删除与导出** 的 Windows 桌面工具。

它不是一个简化版剪映，也不试图成为完整 NLE。它只解决一件事：

> 打开一个视频，在可视化时间轴上快速找到位置、切开、删除不需要的片段，并将剩余或选中的片段按原始时间顺序导出。

核心目标是：**少一步操作、少一次重新编码、少一点等待。**

---

## 特性

### 可视化时间轴

- 连续视频缩略图
- 音频波形
- 时间刻度尺
- 播放头 / Scrub
- 切点、片段、删除 Gap 可视化
- Timeline 横向缩放 / Fit
- Ctrl + 鼠标滚轮围绕鼠标位置缩放
- 深度放大时支持毫秒级时间刻度
- Timeline 高度可自由拖动调整

### 专业化选择与导航

提供两种 Timeline 工具：

- **V - 选择工具**：选择片段、Ctrl/Shift 多选、拖框选择、Trim
- **H - 手型工具**：直接按住 Timeline 左右拖动视口

同时支持：

- 左侧片段列表与 Timeline 双向同步选择
- Ctrl + 左键追加 / 取消选择
- Shift + 左键连续范围选择
- Ctrl + Shift + 左键追加连续范围
- 鼠标拖框选择
- Ctrl + 拖框追加选择
- 中键拖动 Timeline 平移

### 切片编辑

- `S` / `Ctrl+B`：在播放头位置切开
- `Q`：保留左侧
- `W`：保留右侧
- `Delete`：删除选中片段
- 拖动片段边缘进行 Trim
- 合并连续片段 / 取消人为切点
- 恢复被删除区域
- Undo / Redo
- In / Out 点
- Marker
- 上一 / 下一切点导航

删除片段后不会把后面的内容自动吸附到前面。

时间轴始终保留原始视频的 Source-Time Map：

```text
A | B | C | D

删除 B：

A | [ Gap ] | C | D
```

因此所有片段始终保持原视频中的真实时间位置。

## 导出模式

### 无损模式

使用 FFmpeg Stream Copy，尽量直接复制原始视频/音频码流，不重新编码。

特点：

- 零重新编码
- 导出速度非常快
- 不产生二次画质损失
- 文件大小通常接近原视频对应保留时长的比例

限制：H.264 / H.265 等长 GOP 编码的视频无法保证在任意帧进行真正的无重编码切割，因此实际安全边界可能需要对齐关键帧。

### 精准模式

按用户指定的编辑点进行精准导出，需要重新编码。

特点：

- 可以获得更精确的切点
- 适合需要帧级边界的场景
- 导出速度慢于 Stream Copy
- 文件大小和画质取决于重新编码参数

> 当前版本没有将“整段重新编码”包装成 Smart Render。未来如实现 Smart Cut，将只重新编码边界 GOP，其余主体保持原码流。

## 导出能力

- 导出当前片段
- 导出选中片段
- 导出全部片段
- 多选片段始终按照原视频时间顺序导出，而不是点击顺序
- 自动连续编号：`001.mp4`、`002.mp4`、`003.mp4` ...
- 可选文件名前缀
- 文件名冲突保护
- 预计输出大小
- 导出进度
- 取消导出
- 单个片段失败不会直接终止整批任务
- 导出完成后可直接打开输出目录

## 技术栈

- **Python**
- **PySide6 / Qt** - Windows 桌面 UI
- **FFmpeg / FFprobe** - 媒体解析、缩略图、波形、Stream Copy 与精准导出
- **PyInstaller** - Windows 独立可执行程序打包

---

### 任意帧无损切割

对于 H.264 / H.265 等基于 GOP 的编码格式，任意帧位置无法天然通过 Stream Copy 完成完全精确的切割。

因此：

- **无损模式**优先保证不重新编码
- **精准模式**优先保证切点准确
